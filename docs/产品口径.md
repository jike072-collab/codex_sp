# 产品口径

## 第一版定位

这是本地鞋类广告视频工作台。普通用户只需要：

1. 打开工具。
2. 新建项目。
3. 上传鞋类图片。
4. 选择单段或双段视频模式。
5. 按步骤确认产品、脚本、故事板。
6. 进入导出计划。
7. 生成、预览或下载视频结果。

普通前台不展示 API Key、供应商、模型、调试日志、内部 prompt 或复杂参数。

## 当前模式

- 单段 5-15 秒：数据模式 `single_video`，新项目默认模式，一条完整脚本、一张 `full` 故事板、一个视频任务。
- 双段 20 秒：数据模式 `legacy_multi_segment`，用户界面不显示 legacy/旧版，两个 10 秒脚本段、两张故事板、两个视频任务。

两个模式共用同一套五步流程，只在时长、脚本分段、故事板数量和视频任务数量上不同。

## 当前代码事实

- 新建项目默认 `workflowMode: "single_video"`。
- 前台模式切换入口在项目标题区域右侧。
- 切换模式若已有脚本、故事板或视频，必须提示会清除后续结果并二次确认。
- img2img 生成必须携带上传的鞋类参考图，不允许 prompt-only fallback。
