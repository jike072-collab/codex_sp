# 产品口径

## 第一版定位

这是本地鞋类广告视频工作台。普通用户只需要：

1. 打开工具。
2. 新建项目。
3. 上传鞋类图片。
4. 选择单版或双版视频模式。
5. 按步骤确认产品、脚本、故事版。
6. 进入生成视频。
7. 生成、预览或下载视频结果。

普通前台不展示 API Key、供应商、模型、调试日志、内部 prompt 或复杂参数。
普通前台也不展示左下“本地模式 / 生成服务”和右上“已保存到本地”这类运维状态。

## 当前模式

- 单版 5-15 秒：数据模式 `single_video`，新项目默认模式，一条完整脚本、一张 `full` 故事版、一个视频任务。
- 双版 20 秒：数据模式 `legacy_multi_segment`，用户界面不显示 legacy/旧版，两个 10 秒脚本段、两张故事版、两个视频任务。

两个模式共用同一套五步流程，只在时长、脚本分段、故事版数量和视频任务数量上不同。

顶部可见流程只保留五步：商品素材、产品设定、生成脚本、生成故事版、生成视频。
内部 `market/创意确认` 状态属于第二步产品设定的保存结果，不作为第 3 步或额外步骤展示。

## 当前代码事实

- 新建项目默认 `workflowMode: "single_video"`。
- 前台模式切换入口在项目标题区域右侧。
- 切换模式若已有脚本、故事版或视频，必须提示会清除后续结果并二次确认。
- img2img 生成必须携带上传的鞋类参考图，不允许 prompt-only fallback。
- 顶部步骤条使用五个方块卡片，保留原先步骤卡的完成、当前、未完成状态和动画口径。

## 2026-06-14 用户最新 UI 纠正

- 顶部五步流程继续只显示五个方块步骤：商品素材、产品设定、生成脚本、生成故事版、生成视频。
- 顶部五个步骤框使用回最开始的方块卡片样式和原有交互动效，不改成目标图里的圆点横线步骤条。
- 可以优化颜色、间距和可读性，但不能把五步框改成另一套控件形态。
- 右侧 AI 检查面板必须保持可读，不能因为步骤框样式回退而被转场、只读态或透明度样式压淡。
