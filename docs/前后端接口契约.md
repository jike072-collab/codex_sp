# 前后端接口契约

## 权威契约

当前接口以这些文件为准：

- `docs/contracts/demo-loop-api.md`
- `docs/contracts/video-generation-api.md`
- `docs/contracts/local-settings-api.md`
- `schemas/studio-project.schema.json`
- `schemas/workflow-mode-api.schema.json`

不要在前台猜字段、猜状态或新增临时状态名。缺字段时先补契约，再实现。

## 关键入口

- `GET /api/projects`
- `POST /api/projects`
- `POST /api/projects/:projectId/assets`
- `POST /api/projects/:projectId/analyze`
- `POST /api/projects/:projectId/review`
- `POST /api/projects/:projectId/market`
- `POST /api/projects/:projectId/script/generate`
- `POST /api/projects/:projectId/script/confirm`
- `POST /api/projects/:projectId/visual/generate`
- `POST /api/projects/:projectId/videos/generate`
- `GET /api/projects/:projectId/videos/status`
- `POST /api/projects/:projectId/videos/:segmentId/retry`
- `GET /api/projects/:projectId/videos/:segmentId/download`
- `PUT /api/projects/:projectId/workflow-mode`

## 前台不得暴露

- 完整 API Key。
- 供应商请求体、prompt、base64 图片、视频内容。
- 模型供应商的内部错误原文全文。
- 本机文件系统绝对路径。

## 本轮已验证

- Node 测试 63/63 通过。
- 单段/双段模式、故事板数量、视频任务数量、provider key 脱敏、脚本重复检测已有自动化覆盖。
- 桌面浏览器 `1440x900` 首屏和项目工作区无控制台 error/warning。
