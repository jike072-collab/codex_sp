# 单人本地版产品基线

## 目标

把一组鞋子多视图图片，逐步转成经过人工确认的广告生产包。用户始终能看见、修改并确认关键中间结果。

## 第一版闭环

`创建项目 -> 上传素材 -> 选择单段/双段 -> 产品识别 -> 人工确认 -> 市场与创意 -> 脚本 -> 故事板 -> 导出计划 -> 预览或下载`

## 产品原则

- 本地优先：项目、图片和生成结果默认只保存在本机。
- 人工可控：产品锁定、卖点、脚本和视觉资产都设置明确审核节点。
- 单商品优先：先把一款鞋的一条广告生产链做稳定，再扩展批量能力。
- 证据优先：区分图片可见、合理推断和用户提供的信息，禁止虚构性能参数。
- 可恢复：每个阶段独立保存，失败后从当前阶段继续，不重新跑完整流程。

## 页面流程

1. 项目：首页查看项目状态并创建项目。
2. 素材：上传同一款鞋的图片素材，检查角度是否完整。
3. 产品锁定：AI 提取鞋型、颜色、鞋面、鞋底、图案和禁止修改项。
4. 模式：选择 `单段 5-15 秒` 或 `双段 20 秒`。
5. 市场创意：选择国家、人群和创意方向。
6. 脚本：审核单条或双段脚本及本地化文案。
7. 视觉资产：按第二步比例生成一张或两张故事板。
8. 导出：进入导出计划，整理视频任务、预览和下载结果。

## 暂不处理

- 用户账号、团队权限、云端同步
- 自动调用视频生成 API
- 多商品批量队列
- 计费、配额和租户隔离
- 复杂素材检索与标签系统

## 前台约束

- 不展示 API Key、供应商、模型、prompt、调试日志和复杂配置。
- 普通用户应只看到项目、步骤、确认动作、生成状态和下载入口。
